1. PROJECT OVERVIEW

Football Ultimate Hub (FUH) is a football-themed website developed for football fans and EA Sports FC Ultimate Team players

The website brings football-related content together in one place, including featured players, football images, videos, football information and useful resources

The project focuses on creating an attractive, user-friendly and responsive website with a professional dark design and blue accents

2. WEBSITE PURPOSE AND OBJECTIVES

The purpose of Football Ultimate Hub is to provide football fans with an online platform where they can explore football-related content

The main objectives are:

- To provide information about featured football players
- To display football-related images and videos
- To provide information about football-related services
- To allow visitors to submit enquiries and contact messages
- To create an interactive and user-friendly experience
- To make the website accessible on different screen sizes

3. WEBSITE PAGES AND FEATURES

3.1 Home Page

The Home page introduces visitors to Football Ultimate Hub. It features football players such as Lionel Messi, Neymar Jr and Luis Suárez

It also includes an interactive Football Fact of the Day button that displays different football facts when clicked

3.2 About Us Page

The About Us page explains the purpose and background of Football Ultimate Hub, including its mission and vision

3.3 Services Page

The Services page presents the football-related services and information available through the website. It also includes an enquiry form with JavaScript validation and feedback

3.4 Gallery Page

The Gallery page displays football-related images and video. It includes an interactive image lightbox that allows visitors to click an image and view an enlarged version against a dark background

Visitors can close the lightbox using the close button, clicking outside the image or pressing the Escape key

3.5 Contact Us Page

The Contact Us page provides contact information and a contact form. JavaScript validation is used to check the submitted information and display feedback

4. CSS DESIGN AND STYLING

CSS3 is used to control the appearance, layout and responsiveness of the Football Ultimate Hub website

The stylesheet is saved in CSS/style.css and provides styling for the website

4.1 Colour Scheme

The website uses a dark football-inspired colour scheme

- Dark navy (#050b14): Main website background
- Dark grey (#111 and #222): Used for the header, footer and navigation background
- Blue (#1683ff): Used for navigation hover effects, buttons and highlights
- Dark blue (#0f6dcc): Used as the button hover background
- Gold (#d4af37): Used for content cards, player cards and service cards
- White: Used for text to provide contrast against dark backgrounds

4.2 Font and Typography

The website uses the Arial font family with a sans-serif fallback. The body line-height is set to 1.6 to improve readability

Different heading sizes are used to create a clear content hierarchy

4.3 Header and Navigation

The header uses a dark background, white text, centred alignment and 20px padding

The navigation menu uses a dark grey background. Navigation links are bold, white and have no underline. When visitors hover over the links, the text changes to blue

4.4 Main Content Layout

The main content uses 90% of the available width, with a maximum width of 1200px. Automatic margins centre the content on the page

Margins and padding are used to create spacing between website sections

4.5 Cards and Player Layout

The website uses gold content cards with rounded corners, padding, borders and box shadows

The player section uses CSS Grid with three columns on larger screens and spacing between the cards

Player cards are centred and include a hover animation that moves each card upwards by 5px

4.6 Buttons

Buttons use a blue background, white text, rounded corners and padding. A darker blue background appears when visitors hover over a button

4.7 Images

Images are styled to fit within their containers without exceeding their maximum width

Player images use a maximum height of 300px, with rounded corners and object-fit: cover

The hero image has a blue border, rounded corners and a maximum height of 500px

4.8 Footer

The footer uses a dark background with white, centred text, 20px padding and a top margin to separate it from the main content

4.9 Responsive Design

CSS media queries are used to adjust the website layout for different screen sizes

- Tablet screens (900px and below): The player grid changes from three columns to two columns
- Mobile screens (600px and below): The main content width changes to 95%, navigation links are arranged vertically, and the player grid changes to one column

These adjustments help the website display more effectively on smaller screens

5. JAVASCRIPT FUNCTIONALITY

JavaScript is used to make the website interactive and improve the visitor experience

The main JavaScript features include:

5.1 Football Fact Generator

The Home page includes a Football Fact button. When visitors click the button, a football fact is displayed on the page

5.2 Services Enquiry Form Validation

The Services page includes JavaScript form validation to check the information entered by visitors and display a successful submission message when validation passes

5.3 Contact Form Validation

The Contact page uses JavaScript validation to check the contact form information and display feedback after successful validation

5.4 Gallery Image Lightbox

The Gallery page includes a lightbox feature. When visitors click an image, an enlarged version appears over a dark background

The lightbox can be closed using the close button, clicking outside the image or pressing the Escape key

5.5 Interactive FNB Stadium Map

The Contact page includes an interactive map created using the Leaflet JavaScript library. The map displays the location of FNB Stadium in Nasrec, Johannesburg, South Africa.

CARTO map tiles are used to display the map background, while a marker identifies the stadium’s location. Visitors can zoom in and out and select the marker to view the stadium’s name and location.

Technologies used:

- Leaflet – JavaScript library used to create the interactive map.
- CARTO – Provides the map tiles used as the map background.
- OpenStreetMap – Provides map data and is acknowledged in the map attribution.
